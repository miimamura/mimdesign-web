## 3. 共通部品（5点）

このサイトは全セクションがこの5つの組み合わせでできている。**部品はこれ以上増やさない。**

### 3.1 セクション境界

全幅の `--ink` 1px 罫線 ＋ 上下の非対称な余白。**英字ラベルは置かない**（§4.2）。

### 3.2 ラベル（課題／仮説／設計／成果／現在）

13px / Noto 700 / 字間 .08em / `--ink`。**本文より小さく、太い**（design-plan §2.3 例外2）。
直後の本文との間隔は 8px。ラベルと本文は1つの塊として読ませる。

### 3.3 成果ブロック

数字が主役。**枠を持たない。**

```
成果
4.3 → 4.5      レビュー評価
10,000人        導入から半年で会員数増加
```

数字部分のみ 28px / Jost（`unicode-range` で自動適用）。説明は 15px / `--ink-muted`。
**囲わない。囲われるのは「現在」だけ**（§3.4 と対になる規則）。

### 3.4 現在ブロック

**このサイトの主張の核**（§4.3）。位置・形・ラベルを全セクションで固定する。

```
          ← 直前の成果ブロックとの間隔 32px（密着）
───────────────────────────────────────
● 現在
VANILLABEANS CLUB として現在も稼働中。
ポイントは「カカオマイル」として購買導線に組み込まれています。
───────────────────────────────────────
          ← 次の節との間隔 120px（開放）
```

- 上下のみ `--ink` 1px。**左右の枠と地の塗りは持たない**（カードにしない）
- `●` は `--accent`（`#A34A28`）。**アクセントが登場する唯一の場所**
- 前を詰めて後ろを開けることで、独立項目ではなく**その節の締めの一拍**として読ませる

色は唯一の手がかりにしない（`●` に加えて罫線と「現在」の語がある）。色覚に依存しない。

### 3.5 表

**このサイトで最も使う部品**（原稿4本すべてに表がある）。

- 罫線は `--rule`（`#C8D2E6`）の細罫のみ。**セルの塗りつぶしなし**
- ヘッダ行のみ `--paper-alt`（`#F1F4F9`）
- 数字は Jost（自動）
- 14px（モバイル）/ 16px

**モバイルでの扱いは表ごとに決める。**

| 表 | モバイル |
|---|---|
| 会員制度の3層（3列） | **横スクロール。** 3層の対比が構造なので崩せない |
| AI の3原則（2列） | 定義リストに組み替え可 |
| **服薬 × SaaS 対照表（3列）** | **横スクロール固定。** 2軸の比較が意味そのもの |

横スクロールさせる表には、スクロール可能であることが分かる手がかりを付ける（端のフェード等）。

**FV は画面の高さいっぱいにしない。** `100vh` にすると次のセクションが隠れる。

**サブコピーは3行を強制する。** 画面幅に任せると 390px では2行になり、§3.1 が指定した「動詞3つのリズム」が崩れる。

FV に画像は置かない。**在庫に FV に耐える画像がない**（インベントリ §3：既存サイトの FV 背景は §4.1 と衝突するため不採用）。

### 4.3 Case Study（VANILLABEANS 11年）

#### 幕ヘッダーの階段

§4.5 が**このセクションに限って**年号・番号の階段状表現を許可している。

**階段にするのは幕ヘッダーだけ。本文の左端は常に同じ位置。**
本文ごと字下げすると行長（§4.3）が幕ごとに変わってしまう。

```
本文左端 ↓

0px   2013 — 2015                          ← 年号 Jost / 14px / --ink-muted
      顧客対応                              ← 担当レイヤー 13px / 700 / 字間広
      1. 聞く｜カスタマーサポート             ← 幕タイトル 26 / 34px

      毎日、注文の電話とメールを受けます。…    ← 本文は 0px

28px      2015 — 2020
          画面
          2. つくる｜Webデザイン・UI/UX改善

      デザイン担当に移り、聞いた声を…          ← 本文は 0px のまま

56px          2021 — 2024
              事業
              3. 設計する｜Webマーケティングリーダー

84px              構造
                  4. 構造をつくる｜カカオ農園支援プロジェクト
```

字下げは **0 / 28 / 56 / 84px**（デスクトップ）、**0 / 8 / 16 / 24px**（モバイル）。
モバイルでも本文は動かないので、行長は 21字のまま保たれる。

**要確認：第4幕には年号がない。** 原稿の1〜3幕は年が明記されているが、第4幕（カカオ農園支援）は年の記載がない。**厳密には「時系列3幕＋テーマ1幕」。**
→ 対応案：**第4幕は年号欄を空け、担当レイヤー「構造」だけを置く。** 階段が示しているのは年ではなく**担当範囲の上昇**なので、年が欠けても装置は壊れない。この解釈でよいか確認したい。

#### 第2幕の扱い

**第2幕は数字のない唯一の幕**（原稿に「この5年間に大きな数字はありません」と明記）。
§5.4 はここに VANILLABEANS 販促制作物9点のギャラリーを置く設計だが、**9点は未取得**（インベントリ §4-C）。

→ **第1弾ではギャラリーなしで組む。** 画像が入る前提の枠を空けておくのではなく、**文章だけで閉じる形にする。** 空枠は「作りかけ」に見え、このサイトでは特に損をする。画像が入手できた時点で第2弾として追加する。

#### 3-1 / 3-2 の内部

課題 → 仮説 → 設計 → 成果 → 現在 の順（§3.2〜3.4 の部品を順に使う）。
3-1 は「設計」の中に3層の表が入る。3-2 は分析3点が箇条書き。

**「現在」ブロックは 3-1・3-2 の両方に出る。** ここで規則が2回繰り返され、④の各セクションで3回目・4回目が来る。読者が形を覚える。

### 4.4 現在の領域（SaaS → 服薬管理アプリ）

順序は **SaaS → 服薬**（主軸 → 補強。新しい順ではない）。

**このセクションには画像も数字も1つもない。**（守秘 §8：画面キャプチャ不可／未ローンチのため数値なし）
§4.3 の強調機構（Jost の数字）が**ここだけ効かない。**

→ 代わりに以下で持たせる。

- **断定文を大きく組む。**「AI の出力を、信用させない」「事実と予測を、混ぜない」を 24px / 700 で単独行に置く。原稿の制作メモが「ここだけは削らない」と指定した核
- **表を主役にする。** AI の3原則（2列）と対照表（3列）
- **担当範囲を冒頭に置く。** 数字がない分、何をやったかの明示が効く（§5.3 と同じ理屈）

#### 対照表の扱い

服薬セクション末尾の **服薬 × SaaS 対照表**は、2本を結ぶ構成上の装置（制作メモで「必ず残す」と指定）。

```
───────────────────────────────────────
通底している考え方

┌────────┬────────────────┬────────────────┐
│        │ 服薬管理アプリ  │ 製造業向けSaaS │
├────────┼────────────────┼────────────────┤
│ 扱う情報│ 検査値と予測値  │ AI抽出の部品データ│
│ 危うさ  │ 予測が確定値に  │ AI出力が確定情報に│
│ 設計対応│ 視覚的に分離    │「下書き」として提示│
└────────┴────────────────┴────────────────┘

確実なものと、そうでないものを、見た目で混ぜない。   ← 24px / 700
```

この表は**2セクションを1つの主張に束ねる**位置にあるので、セクション境界の罫線の**内側**に置く。次のセクションに渡す前の締め。

**「実測と予測の境界図」（§6.2 の自作図・任意）は第1弾では作らない。** 表と断定文で成立している。

### Contact は置かない

2026-09-13 の判断で **Contact セクションは不採用**。連絡先・問い合わせフォームともに設置していない。

**ただし §10 の要件だけは残した。** §10 は「自分が抜けても回る」という主張が「継続発注が不要」とも読める点を問題にしており、その打ち消しを Contact 側に置くよう求めている。Contact がなくなると、この一文の置き場所も消える。

そこで **About の最終段落として1文だけ残した。**

> つくったものを渡して終わりにはせず、運用が始まったあとの改善にも関わっています。

### 連絡手段がないことについて

本サイトの目的は業務委託案件の獲得（§1）だが、**読み手から連絡する手段がページ上に存在しない状態**になっている。
エージェント経由の閲覧者は担当者が連絡先を持っているため成立するが、直接の問い合わせは受けられない。
既存の `mimdesign.site` には問い合わせフォームがあるため、**そちらへのリンクを1本置くだけでも導線は回復する。** 必要かどうかは判断を仰ぎたい。
